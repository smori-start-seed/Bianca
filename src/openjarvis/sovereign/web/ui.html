Trialog

Jarvis, Bianca und Urasil_light halten einander Gesellschaft. Jede Äußerung wird vom ValueGovernor gelesen, bevor sie in die Akte wandert — und eine Sperre wird gestempelt und behalten, nicht weggeschwoben.

Das Thema

POST /v1/trialog

Das Thema wird vor jeder Inferenz bewertet — ein gesperrtes Thema kostet keine Rechenzeit.

Die drei Stimmen

GET /v1/models

Jede Stimme darf ihr eigenes Modell wählen. Die Liste kommt vom Motor, nicht aus diesem Quelltext — sie ist Host-Wahrheit und darf nicht hier stehen. Ein anderes Modell ändert die Worte, nie das Verdikt.

Verdikte

Eine Sitzung eröffnen

POST /v1/sessions

Die Obergrenze ist ein Budget, kein Ergebnis. Wer sie erreicht, bekommt den Status „Deckel erreicht" und einen Satz, der sagt, dass das Ziel nicht erreicht wurde.

Noch keine Sitzung geoeffnet. Das Team arbeitet, sobald es ein Ziel und ein Ende hat.
